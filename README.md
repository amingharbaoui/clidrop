
# clidrop
A simple tool to share files between devices connected to the same Wi‑Fi network.
## Usage/Examples


    Start the application by running clidrop-1.0.exe.

    Type 'help' to list all available commands.

    To send a file from this PC, run:
    > send C:\path\to\file.txt

    To receive files on this PC, run:
    > receive

    To exit the application, run:
    > quit or exit



## Installation

    1. Download the latest release archive from the project releases.
    
    2. Unzip the folder.

    3. Open the .exe file.

    4. Enjoy!
